# 奔饭 Project：致远桥逆流

这是基于 Taisei 的 C / SDL3 / WebGL 2 分支。射击与避让使用同一套引擎和校园关卡；不是独立 Canvas 游戏。

## 初版规则

四位可选角色是虚构的学生类型：国际部、高一、高二、高三。不是现实个人。
国际部早去时稀疏，去程其他角色会遇到从背后追上的同学。所有角色在回程面对迎面人流。

|角色|正常速度|慢行速度|借过持续帧数|射击特点|
|---|---:|---:|---:|---|
|国际部|5.6|2.2|120|三路扩散|
|高一|6.3|2.8|140|双路直射，移动最快|
|高二|5.9|2.5|160|双路直射，移动均衡|
|高三|5.2|1.9|180|双路直射，单发更强|

速度为每帧游戏单位，固定逻辑 60 FPS。碰撞与擦弹由泰西处理。
X“借过”消耗引擎 Bomb 库存，在身边连续打开局部通路。Z 在射击版发射抽象信号；避让版不发射。
射击版 Boss 表示人流的编排者，用血量与符卡承载战斗，不对应现实学生。
避让版关底是固定时长的人流挑战，没有必须击倒的目标。

|关卡|地点|主要变化|
|---|---|---|
|一面|出楼|出发、稀疏直行|
|二面|湖边|结伴、错位通道|
|三面|致远桥去程|桥景、密度提升|
|四面|食堂|队列、节奏放缓、取餐过场|
|五面|回程汇流|三路斜向合流|
|六面|致远桥逆流|迎面高峰|
|Extra|晚去奔饭|迎面与后方人流叠加，后方预警 90 帧|

Extra 当前用引擎支持完整的 Lunatic 难度承载，独立开放。六面以评分画面衔接，通关不播放原版东方剧情。
初版主线每面约 40–100 秒；Extra 射击三阶段，避让末段持续 36 秒。

## 美术与完成度

场内玩家和人流使用程序绘制的学生符号，四种配色。校园背景为路线示意，没有精确复原原地图。
角色选择界面、Bomb 立绘、射击版 Boss、UI 和音乐仍复用 Taisei 原素材。菜单里明确提示占位。
四名角色尚无原创姓名、人物立绘和校园剧情；七关目前共用可配置人流系统，尚非七个完全独立的演出关卡。
手机提供屏幕按键，复杂多指手感还需实机反馈。

## 已核实资料与设计用途（2026-11-15）

- 学校官网：https://www.tyzx.com.cn/
- 餐厅菜单栏目：https://www.tyzx.com.cn/hqfw/zjdt ：可核实一楼、二楼餐厅菜单公示；后续可发展楼层路线。本版没有编造具体每日菜品。
- 校园内部设施：https://www.tyzx.com.cn/tyyj/xyss/nbss ：建筑和食堂设施的后续参考。
- 食堂展示柜报道：https://www.tyzx.com.cn/dytd/xzzs/content_15537 ：可为四面加入展示柜背景提供依据。本版暂未制作。
- 锡山区 2025 年“无锡有点甜”进校园报道：https://www.jsxishan.gov.cn/doc/2025/05/20/4576885.shtml ：一次美食活动，不能推定为日常菜单或整体口碑。

没有找到足够可靠、可归属本校学生的第一手食堂评论，所以本版不引用“学生评价”，也没有把其他学校的评论移植过来。
早去清静、回程逆流、晚去后方追赶及地图标注来自用户叙述。关卡时间和角色数值是游戏设计，不是学校真实作息。
