# v0.1 验证记录

2026-11-15，macOS / Apple Silicon。本地修改使用同一份 C 源码编译为原生版本和 WebAssembly。

- 原生构建通过；Meson 的 format_strings、shader_transpiler 两项测试通过。
- Chrome 无头 WebGL 2（SwiftShader）检查两套规则、四名角色共八个启动场景；覆盖主线入口与一至六面、Extra。没有脚本崩溃或资源 HTTP 错误。
- 网页角色和关卡选择能正确跳转游戏入口；390px 页面无横向溢出。
- GitHub Pages 发布成功；两个线上首页返回 HTTP 200，通过网页选择实际进入射击一面与避让 Extra。两者均出现引擎首帧，没有 JavaScript 异常或资源 HTTP 错误。首次启动时后台仍会预取剩余素材。
- 实际画面确认学生人流进入场地，Extra 出现后方预警；不移动会受到碰撞并损失生命，有擦弹计数。
- 射击版持续运行至一面 Boss 符卡阶段，截图确认自机射击、人流与 Boss 同场。
- 发现并修复：Web 发布版没有调试选关参数；Emscripten 4.0.10 大端堆兼容辅助函数缺失；二维背景文字使用错误着色器；屏幕外生成的人流被提前回收。

这些是启动、画面和基础操作检查，不等于所有 4×2×7 组合的完整通关测试。移动端仅检查网页布局与按钮存在，尚未进行手机实机多指操作、Firefox/Safari 或手柄测试。难度、符卡平衡和美术仍需试玩反馈。
